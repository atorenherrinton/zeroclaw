configure_telegram_transcription

Module unix 

Expand description

Local, one-shot voice-key migration. No speech API calls are made. Secrets are read into memory and piped to the native CLI, never put in argv, environment variables, plaintext files, or diagnostic output.

The operator must provide absolute ZEROCLAW_CONFIG_DIR, OPENCLAW_CONFIG_DIR, ZEROCLAW_BIN, and ZEROCLAW_BACKUP_DIR paths.
